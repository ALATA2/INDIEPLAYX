# IndiePlay (v2.4) 🎮

**IndiePlay** è una piattaforma moderna per la distribuzione, acquisto, gioco online e download di videogiochi indipendenti (inclusi titoli retrò come Amiga, Picchiaduro, GDR, FPS, e molto altro).

## ✨ Caratteristiche Principali

- **Autenticazione Sicura**: Firebase Auth con verifica email obbligatoria e login con Google.
- **Doppia Modalità di Gioco**: Supporto sia per il **Download (ZIP)** sia per il **Gioco Online / Cloud**.
- **Avviso & Scarico di Responsabilità**: Disclaimer di sicurezza modale interattivo prima di ogni download.
- **Ottimizzazione Automatica Immagini**: Compressione e auto-scaling integrato via Canvas (profilo, cover, screenshot) per caricamenti istantanei.
- **Area Venditori & Creator Studio**: Creazione e modifica completa dei parametri di gioco (prezzo, descrizione, modalità, immagini, zip, merchandising).
- **Recensioni Certificate**: Abilitate esclusivamente per utenti registrati, verificati e in possesso del gioco.
- **Conformità Legale & GDPR**: Modali Privacy Policy e Cookie Policy completi e consultabili.

## 🚀 Tecnologie

- **Frontend**: HTML5, CSS3 Glassmorphism, JavaScript ES Modules, FontAwesome
- **Bundler**: Vite
- **Backend & Database**: Firebase (Firestore, Authentication, Cloud Storage, Hosting)
- **Deployment**: Vercel & GitHub

## 📦 Installazione e Sviluppo Locale

```bash
# Installa le dipendenze
npm install

# Avvia il server di sviluppo
npm run dev

# Compila per la produzione
npm run build
```
